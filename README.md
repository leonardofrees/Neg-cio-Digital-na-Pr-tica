# Negócio Digital na Prática

Kit digital de marketing para pequenos negócios — e-book, materiais extras e consultoria mensal.

## Site publicado (GitHub Pages)

- **Página de vendas:** `/` → [index.html](index.html)
- **Página de acesso** (enviar só para quem comprou): `/acesso/` → [acesso/index.html](acesso/index.html)

## Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| `01-Ebook` | E-book final em PDF e DOCX, mais o arquivo-fonte HTML |
| `02-Materiais-Extras` | Calendário, roteiros, mensagens, prompts, planilha, checklist, planejamento |
| `03-Consultoria-Mensal` | Oferta comercial da consultoria (3 planos) |
| `04-Pagina-de-Vendas` | Fonte da página de vendas (mesma publicada em `/index.html`) |
| `05-Estrategia-Vendas-Organicas` | Plano de divulgação orgânica (30 dias) |
| `06-Identidade-Visual` | Paleta de cores e tipografia do produto |
| `07-Cadastro-na-Plataforma` | Checklist pronto para cadastro em Hotmart/Kiwify/Eduzz |
| `08-Pagina-de-Acesso` | Fonte da página de acesso (mesma publicada em `/acesso/`) |

## Como publicar com GitHub Pages

1. Em **Settings → Pages** deste repositório, em "Source" escolha a branch `main` e a pasta `/ (root)`.
2. Salve. O GitHub gera uma URL como `https://<usuario>.github.io/<repo>/`.
3. A página de vendas fica em `https://<usuario>.github.io/<repo>/`.
4. A página de acesso fica em `https://<usuario>.github.io/<repo>/acesso/` — não divulgue esse link publicamente, envie só para quem comprou.
